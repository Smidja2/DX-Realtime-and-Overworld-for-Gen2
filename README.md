# DX-Realtime-and-Overworld-for-Gen2

**SUPPORTS UPTO GEN III, use with MODS that enable those**

DX Overworld importer and Realtime Battle - You need Pokemon DX: Gale of Darkness iso

https://smidja2.github.io/DX-Realtime-and-Overworld-for-Gen2/

WASD = move

Mouse = look around

RMB = lock onto the enemy <- very important, this is the core

While holding RMB: W/S = move closer/farther

A/D = circle around the enemy

Shift = move faster

LCTRL = switch between your 4 moves

LMB = use the selected move

X = dodge/air dash

Space = jump or fly upward

C / RCTRL = Flydown

Mouse wheel = zoom

For ground-target moves like Thunder or traps:

Select move → WASD moves the target circle → LMB casts it.

So the basic gameplay is really just:

Move with WASD → hold RMB to fight locked-on → LCTRL picks attack → LMB attacks → X dodges.
